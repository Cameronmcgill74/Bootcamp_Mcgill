# Dealership sales and Leasing Project

This is a java console application that allows user to mange a dealership's vehicle inventory, sell vehicle, and lease vehicle,

# Features

- Search vehicle by price, make, model, year, color, mileage, and type.
- Add and remove vehicle from inventory.
- Sell vehicle and calculate sales taxes, fees, and monthly payment.
- Lease eligible vehicle and calculate lease payments.
- Saves vehicle inventorty and sales or lease contracts to CSV files.
